### Question 11: Score Analysis
*Why do the graphs for the scores in (A) show completely different results from the graphs for the scores in (B)?*
Score A corresponds to the "Real" class probability, while Score B corresponds to the "Fake" class probability. Since Softmax is used, Score A + Score B = 1. Therefore, when Score A is high, Score B is low. The ROC curve for Score A plots the performance of predicting "Real" (Label 0) while Score B predicts "Fake" (Label 1). Since the ground truth labels are 0 for Real and 1 for Fake, using Score A (probability of Real) to predict Label 1 (Fake) yields an inverse relationship (AUC < 0.5 if labels were swapped, but here we likely see the complementary performance). Score B is the direct probability for the positive class (Fake/Label 1).

## Chapter 5: Saliency Maps and Grad-CAM

### Question 29: Saliency Maps
*Explain shortly, in your own words, what Image-Specific Class Saliency Visualisation are.*
Saliency maps visualize the gradient of the class score with respect to the input image pixels. High gradient magnitude indicates pixels that, if changed, would most affect the classification score. This highlights the regions of the image that the model focuses on to make its decision.

### Question 30: Grad-CAMs
*Explain shortly, in your own words what Grad-CAMs are.*
Gradient-weighted Class Activation Mapping (Grad-CAM) uses the gradients of the target concept passing into the final convolutional layer to produce a coarse localization map highlighting the important regions in the image for predicting the concept. It combines the feature maps of the final conv layer weighted by their gradient importance to generate a heatmap.

## Chapter 6: Bonus Part
*Explain how you designed and trained the architecture.*
I designed a lightweight `BonusNet` with ~400k parameters (significantly fewer than SimpleNet's ~17M or Xception's ~23M). The architecture uses 4 blocks of Conv-BatchNorm-ReLU-MaxPool, increasing channels from 32 to 256. Instead of a large Flatten+FC layer, I used Global Average Pooling (GAP) before a small final Linear layer (256 -> 2). This drastically reduces the parameter count while maintaining spatial invariance and forcing the last conv features to be semantically meaningful. I trained it on the Deepfakes dataset for 5 epochs using Adam optimizer. It achieved ~84.2% test accuracy, comparable to SimpleNet but with <3% of the parameters.
